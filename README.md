## CONTEXTUALIZAÇÃO
A **"BiblioTech"** é uma startup que está desenvolvendo um sistema de gestão para bibliotecas comunitárias. O sistema deve permitir que bibliotecas gerenciem seu acervo, controlem empréstimos e reservas, e mantenham um cadastro de leitores.

O objetivo deste projeto é:
1. Levantar e documentar requisitos usando técnicas apropriadas
2. Modelar o sistema usando UML
3. Garantir que o design do código siga princípios sólidos de engenharia de software (SOLID) e baixo acoplamento/alta coesão.

## Estrutura do Projeto
* `/requisitos.md`: Documentação de Requisitos Funcionais, Não-Funcionais, Regras de Negócio e User Stories.
* `/modelagem-uml.md`: Diagramas UML (Classes, Sequência e Atividades) em Mermaid.
* `/analise-design.md`: Análise de violações SOLID e arquitetura do código original.
* `/src/gerenciador_original.py`: Código legado fornecido.
* `/src/emprestimo_refatorado.py`: Código refatorado aplicando SOLID, SRP, OCP e DIP.
